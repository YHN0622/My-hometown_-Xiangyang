# My Hometown — Xiangyang

This website introduces my hometown, Xiangyang, China. It presents the city's local food, historical attractions, and geographic location.

## Website Features

- An introduction to Xiangyang
- Information about local food
- A table showing food prices
- Information about historical attractions
- Interactive Leaflet maps
- Buttons that move the maps to different locations
- A responsive layout for desktop and mobile screens

## Local Food

The website introduces three local foods:

- Xiangyang Beef Noodles
- Xiangyang Brown Sugar Flatbread
- Xiangyang Kongming Pickles

## Historical Attractions

The website introduces three historical attractions:

- Gulongzhong Scenic Area
- Xiangyang Tang City
- Zhaoming Terrace

## Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
- GitHub Pages

## Project Files

- `index.html` — contains the webpage content
- `style.css` — controls the webpage design
- `app.js` — controls the maps and interactive buttons
- `Hometown_image` — contains the images used on the website

## How to Use the Website

Click the map buttons to move between Xiangyang, USC, and the historical attractions in Xiangyang.
